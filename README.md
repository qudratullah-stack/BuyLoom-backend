BuyLoom - Online Shop Backend
BuyLoom is a robust e-commerce backend built with Node.js and Express.js. It handles user authentication, product categorization, and seamless data management for a modern online shopping experience.
🚀 Key Features
User Authentication: Secure Sign-up and Login system using JWT (JSON Web Tokens).
Email Integration: Integrated Resend API for automated emails (Welcome emails, notifications).
Category Management: Dedicated Category Controller to organize products efficiently.
Optimized Data Fetching: "All Data Get" controller to retrieve comprehensive datasets for the frontend.
Secure Data Handling: Password hashing using bcrypt and protected API routes.
🛠 Tech Stack
Language: JavaScript (ES6+)
Runtime: Node.js
Framework: Express.js
Database: MongoDB (Mongoose ODM)
Email Service: Resend API
Security: JWT, bcrypt, CORS, Dotenv
